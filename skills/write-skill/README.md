# Write Skill

Portable Agent Skills package for extracting a new skill from a real workflow or session.

## Install

```sh
npx skills add thedevdavid/skills --skill write-skill
```

Or copy into `~/.agents/skills/write-skill` (shared by Codex / Cursor / Grok-compatible layouts). Claude Code: symlink or copy under `~/.claude/skills/`.

## Use

`$write-skill` / `/write-skill` with the session, corrections, or artifacts to encode. See [SKILL.md](SKILL.md).
