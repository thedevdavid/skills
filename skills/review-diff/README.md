# Review Diff

Portable Agent Skills package for two-axis change review: **standards** vs **intent**.

## Install

```sh
npx skills add thedevdavid/skills --skill review-diff
```

Or copy into `~/.agents/skills/review-diff` (shared by Codex / Cursor / Grok-compatible layouts). Claude Code: symlink or copy under `~/.claude/skills/`.

## Use

`$review-diff` / `/review-diff` with a PR, branch, or base ref plus the ask/spec. See [SKILL.md](SKILL.md).
